# Startup Financial Analysis

## Project overview

This business-planning project applied budgeting, pricing, break-even, funding, and financial-planning concepts to assess startup feasibility and support decisions.

**Date:** 2026  
**Status:** Portfolio reconstruction based on the verified resume description; replace template assumptions with original project inputs before publication.

## Core questions

- What startup and recurring costs must be funded?
- What pricing model supports the intended customer and margin?
- How many units or customers are required to break even?
- How sensitive is feasibility to changes in price, volume, or cost?
- What funding level and operating runway are appropriate?

## Model structure

1. Document assumptions and their sources.
2. Separate fixed, variable, and one-time costs.
3. Calculate contribution margin.
4. Calculate unit and revenue break-even points.
5. Compare base, conservative, and growth scenarios.
6. Identify funding needs, risks, and decision thresholds.

## Key formulas

- Contribution margin per unit = price per unit - variable cost per unit
- Break-even units = fixed costs / contribution margin per unit
- Break-even revenue = fixed costs / contribution margin ratio
- Runway in months = available cash / average monthly net cash outflow

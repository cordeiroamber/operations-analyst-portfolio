# Business Process and MIS Analysis

## Project overview

This case study documents a structured approach to evaluating business processes, information systems, technology integration, and improvement opportunities.

**Context:** Southern New Hampshire University project, 2026  
**Status:** Portfolio reconstruction based on the verified resume description; original coursework artifacts should be added before publication.

## Business question

How can an organization improve a selected workflow by aligning people, process, information, and technology?

## Analytical approach

1. Define the current process and its intended outcome.
2. Identify participants, handoffs, systems, inputs, and outputs.
3. Document delays, duplication, error risks, and information gaps.
4. Gather functional and nonfunctional requirements.
5. Compare improvement options using impact, effort, risk, and adoption criteria.
6. Recommend a future-state process and implementation measures.

## Suggested portfolio artifacts

- Current-state and future-state process maps
- Stakeholder matrix
- Requirements list
- Gap analysis
- Prioritized recommendation
- Implementation roadmap and KPI plan

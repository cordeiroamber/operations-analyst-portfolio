# Publishing Checklist

Complete these steps before publishing the portfolio.

## Required review

- Confirm every education date, credential, honor, and contact link.
- Replace bracketed placeholders with accurate project details.
- Add original, non-confidential coursework outputs where available.
- Remove instructor comments, grades, student IDs, and private metadata.
- Never upload employer, customer, invoice, payroll, or account information.
- Review every analysis and be prepared to explain it in an interview.

## Recommended GitHub setup

1. Create a public repository named `operations-analyst-portfolio`.
2. Upload the contents of this folder, keeping `README.md` at the repository root.
3. Add a professional profile photo only if desired; it is not required.
4. Pin the repository to the GitHub profile.
5. Add the repository URL to LinkedIn and the resume after reviewing all content.

## Strong additions

- Export an original Tableau dashboard as an image and add the workbook or public link.
- Add an anonymized Excel model showing formulas and scenario controls.
- Include a one-page process map for the MIS analysis.
- Add a short presentation or executive recommendation from the fleet analysis.
- Include screenshots of Helping Boldly resources only when they contain no private customer information.

## Integrity standard

Synthetic data and reconstructed frameworks must remain clearly labeled. Do not present generated templates, sample findings, or demonstration queries as completed employer or university work without reviewing and adapting them personally.
